# 3D Truss Structure Analysis — Presentation Website

Static website in Lao for presenting a 3D truss Direct Stiffness Method assignment.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload **all files and the `assets` folder** from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait a short time for GitHub to publish the site.

## Files
- `index.html` — presentation content
- `styles.css` — luxury black/gold design
- `script.js` — section animation, code tabs, reading progress
- `assets/problem.jpeg` — original assignment image

No build system is required.
