CORE EQUATION
\[\{F\}=[K]\{D\}\]

ແຮງ = Stiffness × Displacement

03 · FORMULAS

ອະທິບາຍສູດຕາມລຳດັບໃນ Code

01

ພິກັດ Node

ແຕ່ລະຈຸດເກັບເປັນ Vector 3 ມິຕິ:

\[\mathbf{x}_i=[x_i\; y_i\; z_i]^T\]

ຕົວຢ່າງ G = [4, 0, 4]. ຄ່ານີ້ໃຊ້ເພື່ອຫາຄວາມຍາວ ແລະທິດທາງຂອງ Member.

02

Vector ແລະຄວາມຍາວຂອງ Member

\[\mathbf{L}=\mathbf{x}_2-\mathbf{x}_1\]
\[L=\sqrt{(\Delta x)^2+(\Delta y)^2+(\Delta z)^2}\]

ຫາ Vector ຈາກ Node 1 ໄປ Node 2 ແລ້ວຫາຂະໜາດຂອງ Vector ນັ້ນ.

03

Direction Cosines

\[l=\frac{\Delta x}{L},\qquad m=\frac{\Delta y}{L},\qquad n=\frac{\Delta z}{L}\]

l, m, n ບອກວ່າ Member ເອຽງໄປຕາມແກນ x, y, z ຫຼາຍປານໃດ.

04

Element Stiffness Matrix — 3D Truss

ສະມາຊິກ 1 ອັນມີ 2 Nodes × 3 DOF = 6 DOF.

\[\mathbf{k}^{(e)}=\frac{EA}{L}\begin{bmatrix}l^2&lm&ln&-l^2&-lm&-ln\\lm&m^2&mn&-lm&-m^2&-mn\\ln&mn&n^2&-ln&-mn&-n^2\\-l^2&-lm&-ln&l^2&lm&ln\\-lm&-m^2&-mn&lm&m^2&mn\\-ln&-mn&-n^2&ln&mn&n^2\end{bmatrix}\]

E = Modulus of Elasticity, A = ພື້ນທີ່ໜ້າຕັດ, L = ຄວາມຍາວ Member. ຖ້າ EA ໃຫຍ່ ສະມາຊິກຈະແຂງກວ່າ.

05

Global Assembly

\[[K]=\sum_e [k^{(e)}]\]

ບໍ່ແມ່ນບວກ Matrix ຕົງໆທັງໝົດ. Code ໃຊ້ DOF mapping ເພື່ອນຳຄ່າຂອງ element ໄປວາງໃນຕຳແໜ່ງທີ່ຖືກໃນ Global Matrix.

06

ສົມການຫຼັກຂອງໂຄງສ້າງ

\[\{F\}=[K]\{D\}\]

{F} = nodal force vector, [K] = global stiffness matrix, {D} = nodal displacement vector.

07

Boundary Conditions ແລະ Reduced System

\[[K_{ff}]\{D_f\}=\{F_f\}\]
\[\{D_f\}=[K_{ff}]^{-1}\{F_f\}\]

f = free DOF. Fixed DOF ຂອງ A, B, C, D ມີ displacement = 0, ຈຶ່ງເຫຼືອສະເພາະສ່ວນທີ່ຕ້ອງແກ້.

08

Axial Force ໃນ Member

\[q=\frac{EA}{L}\begin{bmatrix}-l&-m&-n&l&m&n\end{bmatrix}\{D_e\}\]

ນຳ displacement 6 DOF ຂອງ 2 Nodes ທີ່ປາຍ Member ມາ project ໃສ່ແນວແກນຂອງ Member.

q > 0Tension · ແຮງດຶງ
q < 0Compression · ແຮງອັດ

04 · PYTHON WALKTHROUGH

ອ່ານ Code ໃຫ້ເປັນພາສາວິສະວະກຳ

ເວລາ Present ບໍ່ຈຳເປັນອະທິບາຍ Syntax Python ທຸກຕົວ. ໃຫ້ອະທິບາຍວ່າແຕ່ລະ Block ກຳລັງເຮັດຫຍັງທາງ Structural Analysis.

01 · NODE COORDINATES

nodes = {
 'E': np.array([4,0,0]),
 'G': np.array([4,0,4]),
 'B': np.array([0,-2,0]),
 'C': np.array([0,-2,4]),
 'A': np.array([0,2,0]),
 'D': np.array([0,2,4])
}

ສ້າງ Coordinate ຂອງທຸກ Node ໃນຮູບ [x, y, z]. ນີ້ແມ່ນ Geometry input.

02 · MEMBERS

members = [
 ('G','E'), ('G','C'), ('G','D'),
 ('E','B'), ('E','A'), ('E','D')
]

ແຕ່ລະ tuple ແມ່ນ 1 Member. ຕົວຢ່າງ ('G','E') ໝາຍເຖິງ Member GE.

03 · MATERIAL

E_mod = 1.0
A = 1.0

ກຳນົດ E ແລະ A. ໃນ code ນີ້ໃຊ້ 1.0 ເພື່ອສາທິດແບບ normalized; ຖ້າຫາ displacement ຈິງ ຕ້ອງໃສ່ E ແລະ A ຕາມຫົວໜ່ວຍຈິງ.

04 · DOF MAPPING

dof_map = {n: [3*i, 3*i+1, 3*i+2]
           for i,n in enumerate(node_list)}
ndof = 3 * len(nodes)

3D Truss 1 Node ມີ 3 translational DOF. 6 Nodes ⇒ 18 DOF.

05 · ELEMENT STIFFNESS

L_vec = x2 - x1
L = np.linalg.norm(L_vec)
l, m, n = L_vec / L

k = (E_mod*A/L) * np.array([...])

ຫາ Member vector, length, direction cosines ແລະສ້າງ 6×6 stiffness matrix.

06 · ASSEMBLY

for (n1, n2) in members:
    k = element_stiffness(n1, n2)
    dofs = dof_map[n1] + dof_map[n2]
    ...
    K[dofs[i], dofs[j]] += k[i,j]

ວາງ stiffness ຂອງແຕ່ລະ member ເຂົ້າຕຳແໜ່ງຂອງ Global [K].

07 · FORCE VECTOR

F = np.zeros(ndof)
F[dof_map['G'][1]] = -70
F[dof_map['G'][2]] = -40

ສ້າງ vector ແຮງຂະໜາດ 18 ແລ້ວໃສ່ load ທີ່ DOF y ແລະ z ຂອງ Node G.

08 · BOUNDARY CONDITIONS

fixed_nodes = ['A','B','C','D']
fixed_dofs = []
for n in fixed_nodes:
    fixed_dofs += dof_map[n]

Node A, B, C, D ຖືກມອງເປັນ supports ແລະ lock 3 DOF ຕໍ່ Node.

09 · SOLVE DISPLACEMENTS

K_ff = K[np.ix_(free_dofs, free_dofs)]
F_ff = F[free_dofs]
D_free = np.linalg.solve(K_ff, F_ff)

ເລືອກສະເພາະ free DOF ແລ້ວແກ້ linear equations ເພື່ອຫາ displacement.

10 · MEMBER FORCE

T = np.array([-l,-m,-n,l,m,n])
q = (E_mod*A/L) * np.dot(T, u)

Project nodal displacement ເຂົ້າແນວ Member ແລ້ວຄູນ EA/L ເພື່ອຫາ axial force.

11 · OUTPUT

typ = "Tension" if f > 0 else "Compression"
print(f"{m}: {f:.2f} ({typ})")

ຖ້າ q ເປັນບວກ ລາຍງານ Tension; ຖ້າເປັນລົບ ລາຍງານ Compression.
